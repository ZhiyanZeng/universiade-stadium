# 水晶石 · 深圳大运中心体育场

一个面向浏览器实时运行的深圳大运中心体育场（Shenzhen Universiade Sports Center）建筑可视化网页。模型依据用户提供的立面、剖面、楼层平面、看台平面与屋顶平面，并参考项目公开资料建立：20 组六边形晶体折面单元、三层椭圆看台、180 × 130 米屋盖开口、400 米九道田径场、LED 大屏与湖岸场地都可在页面中自由观察。

> 截图未随仓库提供，克隆后本地打开即可查看全部视角、灯效与观众模式。

## 运行

页面使用 ES Modules 与本地 Three.js，**必须通过 HTTP 访问**，不能直接双击 `index.html`：在 `file://` 协议下浏览器会以 CORS 为由拒绝加载模块，页面只会白屏。

在项目根目录任选一种静态服务器：

```bash
# Python（Windows / macOS / Linux 通用）
python -m http.server 8088

# Node.js
npx --yes serve -l 8088 .
```

也可以在 VS Code 里安装 Live Server 扩展，右键 `index.html` → **Open with Live Server**。

Windows 用户可以直接双击 `启动.bat`：默认 8088 端口、自动打开浏览器，`启动.bat 8090` 可换端口，`Ctrl + C` 停止。

打开：<http://localhost:8088/>

Three.js 与所需 addons 已放在 `vendor/`，页面不依赖外部 CDN，断网可用。结构图纸与三维数据全部在本地加载。

## 部署

仓库是纯静态站点：无构建步骤、无后端、无环境变量，可直接托管在 GitHub Pages、Vercel、Netlify 或任意静态服务器上。

**GitHub Pages**

1. 打开仓库 **Settings → Pages**；
2. Source 选 **Deploy from a branch**，分支 `main`、目录 `/ (root)`，保存；
3. 约一分钟后访问 `https://<用户名>.github.io/<仓库名>/`。

页面中所有资源都是相对路径（`styles.css`、`./js/app.js`、`./vendor/three.module.js`），部署到子路径不需要改任何代码。

## 功能

- **六边形晶体单元**：外立面由 20 组六边形晶体组成。每个单元以一枚外凸顶点为核，六条棱线向六边形轮廓放射，形成 6 块三角折面；顶点向外出挑约 14 米，相邻六边形在腰部相接；长边中部的晶体最大最高，向两侧逐渐收小，最高点 51.3 米、两端约 36 米。
- **磨砂玻璃表皮**：外立面由大量等边三角形磨砂玻璃分格组成（三角晶格），高粗糙度、近零金属度，只保留柔和漫射，不做镜面反射；每个晶体的下部两块折面为暖灰石材，棱线以浅色细杆勾出六边形骨架。
- **下沉式看台与内场**：整组看台与田径场/足球场整体下沉 13.8 m，看台顶面与外立面相接，场地低于广场标高，外立面与屋盖高度保持不变。
- **三层看台（第三层只在长边并逐渐收薄）**：底层、中层、上层看台由两条 **3.2 m 等高**的玻璃环带分隔；二层向下多做了两排（14 排），脚部落到 15.8 m 并**向后延伸到环带顶面**，环带就压在二层首排下方，墙顶加了一圈白色压顶，把墙与首排踏面之间的缝封死，坡度也随之放缓（进深 12.2 m 走完 8.6 m 落差）；二层顶部与三层底部之间是等高的环形环廊带，无论长边还是转角，净距处处相同；第三层沿两条长边铺开约 132°，顶缘在长边中点最高（48.7 m），向两端平滑下落 12 m（底缘保持水平），越靠球门越薄，最终落到二层。约 6.79 万个参数化座席，20 条径向踏步通道、四角内场入口通道与 LED 灯带；第三层的踏步通道不加扶手，前两层保留双侧扶手。
- **一层看台落到场边**：内场按 90% 收小（跑道内径 32.85 m、足球场 94.5 × 61.2 m）后，一层看台从 20 排、0.6 m 的首排起坡，首排直接落在跑道外的缓冲坪上，取代原先 3 m 高的挡墙；顶端标高仍为 12.6 m，与二层之间保持原来 4.6 m 的净距。
- **看台入口与环廊平台**：一层顶端、二层顶端各有一圈环廊平台（与二层顶端同做法：从最上一排一直铺到外立面），墙面上每 18° 开一处约 4.1 × 2.7 m 的入口门洞（每道墙 20 处，正对 20 个结构单元，四面八方完全对称），门洞两侧立白色门框、上部压连续檐带；人物视角可以穿过门洞走进环廊，其余墙面挡住去路。
- **夜间座席照明**：夜里不再靠自发光把座椅“提亮”，而是让环境光随太阳落下（IBL 强度按日照系数衰减），再加一盏偏高的月光主光 + 座席踏面微量自发光；白天那种“亮踏面 / 深座椅”的横条对比在夜里保留下来，一排排座椅看得清。
- **LED 大屏**：两块屏立在二层看台顶端、球门后方的环廊楼板上，带独立钢架与斜撑。
- **屋盖**：180 × 130 米椭圆开口、20 个折面单元、内外压缩环、径向主脊、7 米深三角桁架，外缘以深灰钢封边；**屋面只剩两种面**——20 组五边形水晶，加上两组水晶之间那块**三角形覆膜**（从晶体的宽角、也就是单元结构脊上，一路扇到檐口，两条长边就是晶体自己的外棱，等于沿骨架分缝）：覆膜用**和外立面完全相同的磨砂玻璃材质与等边三角晶格**（同一套 4.6 × 8 m 的贴图；屋盖与凸起按**自上而下的平面投影**取 UV，立面按圆柱投影，所以近水平的屋面上三角形依旧是等边的，不会被坡面拉长）；檐口这块膜每侧再切 3 段小平折面顺着晶体冠线走（全是平面折板）；屋盖外缘的峰谷**与六边形晶体的峰谷同相位**；开口环内侧加高 0.5 m 的白色封边把膜与环梁之间的细缝封死；开口环的**内侧面**装 10 组投光灯，每组十盏一字排开（共 100 盏，灯距 2.1 米不重叠），组与组之间留出约 28 米空档，从看台仰视即可看见整排灯具；屋顶平面可单独查看。
- **屋盖脊部凸起（20 组五边形水晶）**：每两个六边形晶体单元的折缝就是一组**五边形凸起**的中轴线。底面是拉直、左右对称的五边形：贴开口环一条短边，**两个宽角正好落在两侧单元的结构脊上**（各半个单元角 = 9°），一路收到檐口、在两组晶体之间的缺口处收成一个尖点——所以 20 组凸起彼此肩并肩贴着，从屋盖平面看就是图纸那张风车。五条棱线从五个角汇到五边形内部的一点，**那个交点就是凸起的顶点**：顶点标高长边约 47 m、短边约 41 m，长边略高、短边略矮。骨架全是直杆（五条棱 + 五条底边），覆膜全是平面三角形，材质与花纹直接复用外立面的磨砂玻璃与等边三角晶格（同样 4.6 × 8 m 的贴图、自上而下的平面投影，屋面与晶体的晶格连成一片）；底面封一块暗色板，从看台仰视看到的是实心底面而不是空腔。**凸起范围内没有任何屋面膜面**，原来穿过这里的两圈环形桁架、以及每个折缝上那根径向杆也一并去掉，所以仰视时晶体内部是干净的；夜里跟着立面一起发光、关灯一起熄灭。
- **顶棚灯组（`U`）**：开口环上那 100 盏投光灯的**总开关**，只管灯组本身（灯珠自发光与光晕），不动外立面洗墙、场地投光和大屏；关掉后频闪与逐个闪烁自然也就看不到了，重新打开即恢复。它与「外立面 / 顶棚关灯」是两件事：关灯管的是洗墙与场地照明，灯组开关管的是这排灯。
- **灯组频闪**：面板开关或按 K，顶棚 10 组投光灯按约 15 Hz 的随机节拍各自明灭，**它们投在场上的光同步跟着闪**——场地投光、场地补光与天光按这 10 组的平均亮度一起起伏，球场、跑道与看台因此出现一波一波的光影；立面洗墙、灯带、LED 大屏等其它灯具本身不参与闪烁（关闭即恢复稳定照明）。它与「关灯」互不影响：关灯时勾选频闪，灯组照样会亮起来闪，关掉频闪又回到熄灭状态。
- **灯组逐个闪烁**：频闪下面的第二个开关（`G`）。效果和「灯组频闪」完全一样——只闪顶棚那 100 盏投光灯、场内光影跟着起伏，**但每一盏灯都有自己的随机节拍**，不再是整组一起亮灭；外立面、膜面、灯带、看台与大屏一律不参与。它与频闪是同一个灯组的两种闪法，二者只互相排斥；与「关灯」同样各管各的。
- **荧光棒星海（`V`）**：演唱会模式。看台上**逐座掷骰子**决定谁举起荧光棒（约 13% 的座位，约 8,700 支），位置还在座位附近随机偏一点、举高也不一样，所以绝不会排成整齐的行列——远看是一片密度不均的星海。**全场同一时刻只有一种颜色**（像真实演唱会里统一控制的荧光棒），颜色自己沿色轮缓慢变化、约 14 秒走完一圈；亮度整体调得比较亮（点更大、纯度更高），只有逐支的细微差别，所以仍是一片有层次的星海，不会显得是同一个像素阵列。**每支还会自己晃**：左右、上下、进出三个方向各走一个时钟，相位逐支随机，幅度几十厘米，看上去就是全场举着棒在轻轻摆动；亮灭也跟着摆动的节奏微颤。加色混合的发光点，配合后期 Bloom 会自然晕开。
- **观众闪光灯（`B`）**：同一批座位里再抽约 10% 的手机屏（约 6,800 点），比荧光棒更密也更白。手机屏是**一直亮着**的，平时只做很小幅度的晃动（位置十几厘米、亮度 ±10%），另外每点会**偶尔快闪一下**（约 5% 的时刻突然变很亮或压暗），像是有人抬手、侧屏。它与荧光棒星海互不影响，可以只开一个，也可以一起开。
- **四角内场通道**：四个 45° 角上的入口从环廊穿过一层看台直达跑道内侧，前缘栏板在此断开。
- **内场**：足球场（草纹、完整白线、球门与球网）、九道田径场、混凝土缓冲区、LED 广告板、替补席与角旗；整块场地按 90% 比例收小，给一层看台让出场边落座的进深。
- **场地与景观**：椭圆石材广场、台地种植带、湖面、木栈道、湖岸置石、棕榈与阔叶林、灯杆、远处山脊与城市轮廓。
- **时间与灯效**：0—24 时滑杆和黎明 / 正午 / 黄昏 / 夜幕预设；**黄昏预设设在 17:33（太阳高度约 +5°）**，太阳压低、色温转橙，广场与草地上拉出很长的建筑投影；冰晶白、翡翠绿、大运蓝、盛典四种灯效；日间采用石材与磨砂玻璃色，夜间以 LED 洗亮折面与环廊。
- **外立面 / 顶棚关灯**：灯效下方的独立开关（`O`），与灯效颜色、与两个灯组开关都互不影响——一键熄灭外立面洗墙灯、折面与膜面的自发光，**场地投光与场地补光也一起关掉**（内场只余月光与天光），落到真正的“闭馆”状态；顶棚那 100 盏灯则听各自的开关：关灯状态下勾频闪/逐个闪，它们仍会亮起来闪，关掉闪又回到熄灭。看台、LED 大屏与广场路灯照旧。
- **日间阴影**：太阳按方位角与高度角实时投影，3072² 阴影贴图覆盖 660 × 660 米场地；屋盖把阴影投在座席与场地上，六边形折面互相遮挡，建筑体量在广场与草地上拖出长影（清晨与傍晚最长）。
- **人物视角（内场 / 一二三层看台）**：点击「内场」直接落到中圈附近；点击「看台」先弹出层数选择（也可按 `1`/`2`/`3`），镜头飞到该层的人眼高度；人物视角内的 HUD 还能随时在三层之间切换。眼高按新要求抬高了：**看台 2.6 m、内场 2.2 m**（比原来的人眼高度高出一截，进来就能越过前排看整场）；`WASD`（或方向键）移动（内场 8.6 m/s、看台 7.0 m/s，按住 `Shift` 分别为 17 / 14.5 m/s）、鼠标转向（点击画面锁定指针，也可按住拖动）、**滚轮调整焦距**（22°—100°，HUD 实时显示当前视角，手机端隐藏该提示）、`Esc` 退出回到原机位；内场活动范围限制在下沉场地内，看台移动沿踏步自动升降，并可以穿过入口门洞走到环廊平台，墙体在门洞之外会挡住去路。
- **参数面板可收起**：右上角「环境」面板标题栏带收起按钮，收起后只留一条标题栏，状态记在本地。
- **结构透视**：一键将玻璃、石材与折面变为半透明，露出折面钢骨架、看台与屋盖桁架。
- **视角**：湖岸、鸟瞰、立面、屋盖为机位预设，内场、一/二/三层看台与自由视角为可操作机位；镜头使用真实时间插值；支持自动环绕、全屏与键盘快捷键。
- **自由视角**：按 `7` 或底部「自由」，镜头脱离地面：`WASD` 沿视线平移（**78 m/s**，比人物视角快得多）、`Space` 上升、`Shift` 下降、鼠标转向、滚轮调整焦距，可贴着晶体折面绕行整座体育场（活动范围限制在场地 900 m 半径、−12.5—340 m 高度内）。
- **看台出门**：一层环廊平台比室外广场低 1.2 m，正好与外立面 20 处入口门厅对位；每处门厅内开一道 5.6 × 3.3 m 的门洞并接一段门槛坡道，人物视角沿“看台 → 入口门洞 → 环廊 → 外立面大门”可以一直走出体育场站到广场上；20 处门厅全部可通行（门洞走廊 ±7 m，其余墙面仍是实体）。
- **可见钢结构加粗、改深灰**：屋盖脊线、环梁、下弦桁架与看台栏板等杆件统一改成**同一粗细**（原始半径 0.12—0.15 m，实例化后约 0.28 m），不再有某一根特别粗的黑杆；颜色统一深灰金属（0x3c4442），在磨砂晶体前读得清楚，也不会穿出玻璃表皮。
- **统一深绿 + 真实光照**：六组三角折面（含原来的石材下半）与屋盖膜面共用同一套中深绿（晶体 0x3d9463、膜面 0x35895a），石材改用玻璃的格纹贴图并按朝向补亮，正午上下两半亮度差 2% 以内；**两个六边形单元之间的折缝不属于折面、也不覆膜**，保持为深色内凹玻璃（0x1d2f28，无格纹、不随日照变绿），门口那三处因此不再像“空洞”。颜色深浅跟着真实太阳走：太阳压低时整体变暗并偏暖，正午回到满值，日落后交给灯具。
- **随时呼出鼠标指针**：任何模式下按 `M` 释放指针锁定——光标回来、准星隐藏，可以直接点面板与图纸；再按 `M`（或点击画面）重新锁定，且不会退出当前机位。
- **图纸档案**：12 张用户提供的图纸/透视图，可在深色图板上放大、切换、下载；另含建筑数据、材料色谱、时间线与公开来源索引。
- **移动端**：竖屏下自动切换远景构图、折叠控制面板与底部紧凑视角栏。

| `V` | 荧光棒星海（看台随机举起、自动变色的荧光棒） |

| `Esc` | 关闭档案 |

深链接示例：`?view=stands&tier=3&time=13.4&mode=emerald&structure=1&archive=drawings`。  
`view` 可取 `shore`、`orbit`、`elevation`、`field`、`stands`、`roof`、`free`；`tier` 可取 `1`、`2`、`3`（看台层数）；`mode` 可取 `crystal`、`emerald`、`ice`、`gala`；`lights=0` 以关灯状态打开，`strobe=1` / `flicker=1` 直接进入频闪或全场乱闪，`sticks=1` / `flash=1` 打开荧光棒星海或观众闪光灯，`lamps=0` 以关闭顶棚灯组的状态打开；`walk=1` 时若视角为内场、看台或自由视角，会直接进入可操作机位（例如 `?view=free&walk=1`、`?view=stands&tier=3&walk=1`）。

## 数据与口径

- **平面尺寸**：采用 schlaich bergermann partner 的 290 × 271 m；中建科工工程报道另写作 270 × 285 m，本页在数据档案中保留这一差异。
- **高度**：51.3 m（钢结构最高点），折面结构厚度约 8.57—12 m。
- **屋盖**：中部开口 180 × 130 m，最大悬挑 68.4 m，20 个球铰支座，用钢量约 18,000 t。
- **看台**：官方赛时容量约 60,000 席；本页参数化座席为 **67,852 席**（一层落到场边多 4 排、二层向下多 2 排，内场相应收小 10%），用于表达真实密度、三层碗形与疏散通道，不逐座编号。
- **资料来源**：以 sbp 项目页、ICON Magazine、e-architect、建筑结构学报摘要、中建科工工程报道交叉核对；用户提供的 11 张结构图与 1 张剖透视作为几何与层数依据。
- **色彩**：日光下的磨砂灰绿玻璃、暖灰石材、白色檐口、深灰钢与近黑的座椅来源于项目照片与照明说明；翡翠绿对应建筑师最初主张的夜间色，盛典模式为赛事期间的多彩照明概念。

## 精度与限制

- 网页是**建筑可视化模型**，不是施工图、BIM 或结构计算模型。折面单元、钢杆件、看台踏步、房间与设备为尺度正确的简化表达。
- 看台的 67,852 个座席由参数化阵列生成，比官方 60,000 席多约 13%：一层为落到场边多做了 4 排，二层为压平环带又向下多做了 2 排，第三层只沿长边布置并向球门方向收薄。
- 外凸折面的曲率依据透视图与立面图重建；实际每单元 13 个三角折面、24 根杆件、8 个节点的细部已概括为「顶点 + 六条棱线」的六面晶体。
- 第三层看台的长度按剖透视取值（约 111° 圆心角）；实际取值以设计图纸为准。
- 湖面反射采用轻量着色器近似，不是光学级水面；树、灯杆、城市轮廓为氛围性配景。
- 图纸、透视图与照片版权归原设计、建设及摄影权利人所有；本仓库仅展示用户提供的图纸，不转载外部摄影。
- 三维几何与网页界面为原创程序化重建，不得标注为官方图纸。
